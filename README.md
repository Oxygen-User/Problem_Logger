# Problem Logger

This project is made to Help people find solutions to their problems easier. "Problems" can be anything, literally anything, like a hardware problem or a software or maybe your car broke down. But the person must percisely log their problems so they can remember it better and help another person.

This includes
- Main menu
- Different subjects in start menu
-  

  Made for [Terra](https://terra.hackclub.com/r/F7S2)

Got some of the assets from [here](https://assetstore.unity.com/packages/2d/gui/icons/2d-casual-ui-hd-82080)
