
# Problem Logger

This project is made to Help people find solutions to their problems easier. "Problems" can be anything, literally anything, like a hardware problem or a software or maybe your car broke down. But the person must percisely log their problems so they can remember it better and help another person.


  Made for [Terra](https://terra.hackclub.com/r/F7S2)

Got some of the assets from [here](https://assetstore.unity.com/packages/2d/gui/icons/2d-casual-ui-hd-82080)

Got the file browser extension from [here](https://github.com/gkngkc/UnityStandaloneFileBrowser)


## How to Open

There are 2 ways to open this project:

### 1

You can download the demo from this [Link](https://github.com/Oxygen-User/Problem_Logger/releases/tag/Demo) (Exit fullscreen or alt + f4 to close the project when opened this way)

### 2

Download this whole repository and view the project altogether on unity editor.

---

## How to Play/Use


- Press Start button to go to the start menu.
- Choose a subject you like.
  - Some of the subjects have pre made examples for the sake of demo.
- Press the "plus" button over top right of he screen to add a new log.
- Press the "minus" button over top right of he screen to delete the current log.
- Toggle edit mode on top of the screen to edit and save your log.
- Use "add img" buttons to add up to 2 images to yur log.
- In edit mode click on the title and the body text to edit them.
- The text's syntax is same as Unity's TMP, so you can utilize those to create more aesthetic text.
